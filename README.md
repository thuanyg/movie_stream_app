
# WatchEz - Movie Stream App
Movie app made in Flutter with clean architecture using Provider and the phimapi.

## Features
- Sign in/Sign up (Authentication)
- Search feature
- Watchlist feature
- Movie video player
- Save to favorite list
- Now playing movies
- Movie by categories
- Popular movies
- Movie details
- Movie cast

## Installation

### Install APK file
- You can install .APK file from [WatchEz-APK_Release.apk](https://htthuan.id.vn/watchez/apk-release/)

### 1. Clone the repo
```bash[
git clone https://github.com/thuanyg/movie_stream_app.git
cd movie_stream_app
```
### 2. Run pub get
```bash
flutter pub get
```
### 3. Add link API into app_constants file
```bash
MOVIE_API_URL = 'API_LINK';
```
### 4. Run the app
```bash 
flutter run
```
